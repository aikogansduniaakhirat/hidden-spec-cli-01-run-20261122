mend applies AI-written edits in four formats — unified diffs with wrong line numbers,
SEARCH/REPLACE blocks, V4A patches and JSON tool-call edits — to a tree of text files,
matching the lines each edit names at three tiers of whitespace tolerance and writing
every change or none.

## Run it

```sh
node main.ts [--format=auto|unified|search-replace|v4a|json] [--check] [--strict] [PATCH]
```
